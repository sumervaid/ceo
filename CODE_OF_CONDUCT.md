# Code of conduct

Be direct and be kind. The two are not in tension. Review the work, not the
person. Assume the other person read the architecture notes and had a
reason. A disagreement about a ledger invariant goes to the invariant until
an issue changes the invariant. Harassment of any kind is not tolerated.

Reports go to sumer@stanford.edu. Every report is read. Every report gets a
response.
